# Безопасность

DubClean рассчитан на локальный запуск и по умолчанию слушает только
`127.0.0.1`. В сервисе нет пользовательской аутентификации и TLS, поэтому его
нельзя напрямую публиковать в локальную сеть или интернет.

Не загружайте непроверенные Python-модули и модельные чекпойнты: PyTorch-модели
следует считать исполняемым доверенным содержимым. Используйте только файлы,
чьи размеры и SHA-256 совпадают с `portable_manifest.json`.

Отчёт об уязвимости следует передавать сопровождающему через приватный канал
репозитория, например GitHub Security Advisories. Не прикладывайте фильмы,
переводы, токены, абсолютные пути и другие пользовательские данные к публичной
задаче.
