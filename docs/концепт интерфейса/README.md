# Интерфейс DubClean

Этот каталог содержит рабочий интерфейс portable-сервиса, который отдаёт маршрут
`/product`.

Набор файлов, необходимый для запуска интерфейса:

- `DubClean-RU.dc.html` — экран приложения и его логика (историческое внутреннее
  имя файла сохранено для совместимости);
- `support.js` — локальная среда выполнения DC-компонентов;
- `HelpDot.dc.html` — единый компонент подсказки;
- `react.production.min.js`, `react-dom.production.min.js`, `babel.min.js` —
  локальные зависимости интерфейса.

Все зависимости интерфейса находятся в этом каталоге: после установки portable-
пакета для работы пользовательского интерфейса доступ в интернет не требуется.
Серверная логика и API находятся в
`python_src/experiments/paired_reference_cancel/app.py`.
