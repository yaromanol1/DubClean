# Проверка публикации DubClean 0.6.0

Проверка выполнена 7 октября 2026 года.

## Состав публикации

- Код сервиса, локальный интерфейс, установочные скрипты, тесты и лицензии.
- DubClean Voice, DubClean M&E и EfficientAT — обычные файлы Git.
- Исходный MossFormer2 SE 48K и дообученный MossFormer Plus — GitHub Releases.
- Размеры, контрольные суммы и адреса загрузки зафиксированы в манифесте.
- Архив исходников содержит небольшие модели; SETUP.bat скачивает два MossFormer.

Фильмы, результаты обработки, проекты и кэш пользователя, статьи-черновики,
виртуальное окружение, локальные инструменты и архивы сборок не публикуются.

## Экспорт чекпойнтов

Три авторских чекпойнта экспортированы отдельно от рабочей установки.
Для DubClean сохранены формат, параметры архитектуры и model_state; для
MossFormer Plus — model. Состояния оптимизаторов, история обучения и локальные
пути исключены. Ни один тензор не изменён: проверены имена, формы и значения
всех параметров. Предобученный MossFormer и EfficientAT сохранены без изменений.
Полные исходные чекпойнты сохранены владельцем в закрытом резервном архиве.
Публичные экспорты предназначены для инференса; оптимизатор для продолжения
исходного обучения находится только в закрытой копии.

## Проверки

- 423 теста Python прошли в режиме исходного checkout.
- SHA-256 всех пяти исходных моделей совпали с авторским манифестом.
- SHA-256 публичных файлов рассчитаны после экспорта и записаны в манифест.
- Обе модели DubClean загружены со строгой проверкой state_dict.
- Оба MossFormer загружены штатным ClearVoice: каждый параметр загруженной
  сети совпал с параметром опубликованного чекпойнта.
- Проверены отказ при неверном SHA-256, сохранение существующего файла при
  сбое скачивания, защита от выхода пути за пределы папки и установка без сети
  при наличии правильных весов.
- FFmpeg 9.0.2 и ffprobe скачаны с официального зеркала GyanD на GitHub,
  проверены по зафиксированному SHA-256 и запущены с -version.
- Torch, TorchAudio и TorchVision зафиксированы совместимым набором
  2.5.1 / 2.5.1 / 0.20.1: clearvoice требует torchvision, поэтому один
  незакреплённый пакет мог бы обновить torch и сломать установленный torchaudio.
- Сборка проверена на личные пути, распространённые форматы ключей,
  пользовательские данные и ограничения размеров GitHub.

Полная установка на Windows без какого-либо Python здесь отдельно не
воспроизводилась: рабочая машина уже содержит Python 3.11. Bootstrap проверяет
подпись установщика Python Software Foundation перед запуском. Рабочая логика
обработки фильмов проверена существующими тестами; новый полнометражный фильм
в рамках публикации не обрабатывался.

## Восстановление

Скачайте исходники и запустите SETUP.bat. Для ручного восстановления моделей
используйте ссылки и пути из portable_manifest.json. Сохранность в GitHub
проверяется по коммиту и контрольным суммам активов релиза. Закрытый авторский
архив дополняет публичную поставку исходными чекпойнтами и документацией;
исходные фильмы, обучающие аудиодатасеты и пользовательские проекты в него
не входят.
