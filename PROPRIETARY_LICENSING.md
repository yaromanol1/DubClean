# Proprietary and commercial use

Commercial use is permitted under `AGPL-3.0-or-later` when all applicable
license obligations are followed.

If an organization wants to distribute DubClean or operate a modified DubClean
network service without providing the corresponding source code as required by
the AGPL, it must obtain a separate written license from every copyright holder
whose permission is required. A separate license can be negotiated through the
maintainer or copyright holder identified on the repository or model page from
which DubClean was obtained.

No website or domain is required or implied.

A separate DubClean license cannot override the licenses of third-party
software, model weights, media or datasets. Those rights must be handled
independently.
