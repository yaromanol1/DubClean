# DubClean

Локальный Windows-сервис для удаления иностранной речи из дорожки русского
закадрового перевода. Сопоставляет оригинал и перевод, выделяет речь, убирает
совпадающую иностранную подложку и собирает русскую дорожку с музыкой и эффектами.
Обработка фильмов выполняется на компьютере пользователя.

## Что нужно на входе и что получится

Нужны оригинальная дорожка и дорожка с русским закадровым переводом одного
фильма. Они могут находиться в одном видеофайле или в двух разных версиях.
Желательно использовать одинаковый монтаж. Несовпадение сцен, скорости или
звукового мастеринга может ухудшить результат.

DubClean не переводит фильм заново и не синтезирует голоса. Задача сервиса
состоит в том, чтобы сохранить существующий русский перевод, убрать из-под
него иностранную речь и вернуть музыку с эффектами.

Сначала строятся короткие превью. По ним нужно проверить результат перед
обработкой всего фильма. Идеальный студийный дубляж не гарантируется:
в сложных местах возможны остатки оригинала, потери фона и артефакты.

## Как устроена обработка

1. Из файлов извлекаются выбранные аудиодорожки.
2. Оригинал сопоставляется с переводом по времени; проверяется совместимость пары.
3. MossFormer2 SE 48K выделяет речь оригинала, а MossFormer Plus — речь
   переводной дорожки, где могут одновременно звучать два языка.
4. DubClean Voice использует сопоставленную оригинальную речь как референс
   для очистки речи перевода.
5. DubClean M&E восстанавливает музыку и эффекты из оригинала. Отдельные
   проверки помогают сохранить песни.
6. Очищенная речь соединяется с фоном. Можно сохранить звуковой результат
   и собрать видео с новой дорожкой без перекодирования видеопотока.

Подробная схема с ветвлениями и ограничениями находится в
[описании конвейера](docs/КОНВЕЙЕР-DubClean.md).

## Установка и запуск

### Полный комплект без скачивания зависимостей

Для запуска без сборки окружения скачайте `DubClean-0.6.0-offline.zip` из
[папки на Google Drive](https://drive.google.com/drive/folders/1IgPA1ktkU2n_j26PsZKzg36jAz1GVme4).
В архиве уже находятся все модели рабочего конвейера, Python с зависимостями,
FFmpeg и ffprobe. Полностью распакуйте ZIP и запустите `START_DUBCLEAN.bat`.
При запуске и обработке ничего не скачивается; фильмы и свои проекты
пользователь добавляет отдельно. Рядом с архивом лежат инструкция и SHA-256.

Это отдельная Windows 10/11 x64 сборка. Для ZIP и распакованной программы
рекомендуется около 12 ГБ свободного места без учёта фильмов и результатов.
На NVIDIA нужен установленный драйвер; без подходящей видеокарты доступен CPU.
Диагностика полного комплекта запускается через `CHECK_INSTALL.bat`.
Если в Windows нет Visual C++ Runtime, откроется включённый установщик
Microsoft; его лицензию и запрос UAC нужно подтвердить вручную, без скачивания.

### Установка из исходников с интернетом

1. Скачайте [архив текущих исходников](https://github.com/yaromanol1/DubClean/archive/refs/heads/main.zip)
   (`DubClean-main.zip`) и распакуйте в отдельную папку.
   Также можно скачать исходники кнопкой **Code → Download ZIP** или через Git.
2. Запустите `SETUP.bat`. Он использует установленный Python 3.11 x64 либо
   устанавливает Python 3.11.9 из python.org с проверкой подписи издателя,
   создаёт `.venv`, устанавливает зависимости, скачивает недостающие модели
   и FFmpeg/ffprobe. Для первого запуска нужен интернет.
3. Запустите `START_DUBCLEAN.bat` и откройте
   [интерфейс сервиса](http://127.0.0.1:8768/product).
4. Для остановки используйте `STOP_DUBCLEAN.bat`; полная диагностика —
   `CHECK_INSTALL.bat`.

`START_DUBCLEAN.bat` также запускает подготовку, если окружение отсутствует.
Установленные модели проверяются по SHA-256; файл с неизвестной контрольной
суммой автоматически не перезаписывается. При ошибке загрузки можно вручную
скачать файл из [релиза v0.6.0](https://github.com/yaromanol1/DubClean/releases/tag/v0.6.0)
и положить по пути из таблицы ниже.

## Первая обработка

1. Откройте локальный интерфейс и создайте проект.
2. Укажите оригинал и версию с переводом, выберите нужные аудиодорожки.
3. Дождитесь извлечения, сопоставления и анализа совместимости.
4. Постройте превью и прослушайте несколько сцен, особенно места с
   одновременной русской и иностранной речью.
5. Если результат подходит, запустите полную обработку и сборку.

Не удаляйте исходные файлы до проверки готового результата. Время обработки
зависит от длительности фильма, оборудования и выбранных параметров.

## Требования

Windows 10/11 x64, около 8 ГБ свободного места без учёта фильмов и результатов.
NVIDIA GPU рекомендуется; доступен режим CPU. Python и FFmpeg устанавливаются
при необходимости. Для установки без автоматического скачивания доступны
[Python 3.11.9](https://www.python.org/downloads/release/python-3119/) и
[FFmpeg для Windows](https://www.gyan.dev/ffmpeg/builds/).
Сервис слушает `127.0.0.1:8768`; многопользовательская аутентификация отсутствует.

## Модели

| Модель | Размер | Путь | Хранение |
|---|---:|---|---|
| DubClean Voice | 15.6 МБ | `models/semantic_ru_separator/dubclean_voice.pt` | репозиторий |
| DubClean M&E | 8.3 МБ | `models/background_restorer/dubclean_me.pt` | репозиторий |
| MossFormer2_SE_48K | 221.6 МБ | `third_party_models/MossFormer2_SE_48K_original/last_best_checkpoint.pt` | GitHub Releases |
| MossFormer Plus | 221.5 МБ | `third_party_models/MossFormer2_SE_48K/last_best_checkpoint.pt` | GitHub Releases |
| EfficientAT MN04 AudioSet | 4.4 МБ | `third_party_models/efficientat/efficientat_mn04_audioset_waveform.pt` | репозиторий |

В репозитории лежат обе модели DubClean и локальный классификатор EfficientAT.
Оба MossFormer сохранены в Releases этого же проекта и автоматически
скачиваются при установке. Дополнительный Git LFS и его квоты не требуются.
Публичные экспортированные чекпойнты содержат параметры сети и конфигурацию
инференса; состояние оптимизатора, история обучения и личные пути удалены.
Каждый тензор сравнен с исходным чекпойнтом: веса не изменены.
Размеры, SHA-256 и прямые ссылки указаны в `portable_manifest.json`.

DubClean Voice также размещена отдельно на
[Hugging Face](https://huggingface.co/Yaromanol/dubclean-voice).
Для работы всего сервиса одной DubClean Voice недостаточно: полный набор
моделей приведён в таблице выше и устанавливается через `SETUP.bat`.

## Что входит в репозиторий

Исходный код, тесты, локальный веб-интерфейс, документация, установочные
скрипты, лицензии и небольшие модели. Фильмы, примеры обработанных фильмов,
пользовательские проекты (`data/`), диагностические результаты (`output/`),
`.venv/`, установленный Python/FFmpeg (`tools/`) и архивы сборок (`dist/`)
исключены из Git. Публичный выпуск не содержит обучающие аудиоматериалы.

## Сборка и проверка

```powershell
python portable_tools/download_models.py
python portable_tools/download_models.py --verify-only
powershell -ExecutionPolicy Bypass -File portable_tools/build_release.ps1 -IncludeModels -Archive
```

Для сборки требуются Python и модели; `build_release.ps1` создаёт новую папку
в `dist` и не перезаписывает существующий комплект. В архив исходников
бинарники FFmpeg не входят и устанавливаются отдельно. В полный offline-ZIP
по ссылке выше FFmpeg уже включён вместе с лицензией и сведениями об исходниках.

Тесты из корня репозитория, в Python-окружении с установленными зависимостями:

```powershell
$env:DUBCLEAN_SOURCE_ONLY = "1"
python portable_tools/configure_portable.py
Push-Location python_src
python -m unittest discover -s tests -p 'test_*.py' -v
Pop-Location
```

Режим `DUBCLEAN_SOURCE_ONLY` позволяет проверить исходники без скачивания
двух больших MossFormer. Для настоящей обработки фильмов полный набор моделей
по-прежнему обязателен. `configure_portable.py` готовит локальные каталоги и
настройки; тот же шаг выполняется в GitHub Actions.

## Ограничения и лицензии

Результат зависит от совпадения монтажа, скорости и мастеринга дорожек.
Проверяйте речевые превью перед полной обработкой. Пользователь должен иметь
право обрабатывать выбранные фильмы и переводы.

## Пометка на обработанной дорожке

Если публикуете обработанную дорожку, можно добавить к названию озвучки
«очищено с помощью DubClean» или «by DubClean». Это добровольная просьба,
не дополнительное условие лицензии. Такая пометка помогает отличить очищенную
версию от исходной и не означает, что DubClean создал сам перевод.
Подробнее — в [ATTRIBUTION.md](ATTRIBUTION.md).

Вопросы по запуску можно оформлять в
[Issues](https://github.com/yaromanol1/DubClean/issues).
Не прикладывайте фильмы, аудиодорожки, токены или журналы с личными данными.
О находках, связанных с безопасностью, сообщайте согласно
[SECURITY.md](SECURITY.md).

## Сохранность проекта

Исходники и небольшие модели сохраняются коммитами Git, большие модели —
активами релизов. Для восстановления скачайте комплект из Releases либо
клонируйте репозиторий и запустите `SETUP.bat`. При выпуске новой версии
сохраняйте старые релизы: манифест содержит ссылки на конкретную версию.
Полные авторские чекпойнты с состоянием обучения хранятся владельцем отдельно
в закрытой резервной копии; они не нужны для работы сервиса.
